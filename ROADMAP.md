# Roadmap

The **Threat Scenario-Based Detection Use Case Framework** is being developed incrementally. The roadmap focuses on proving the methodology through reproducible artifacts rather than expanding the framework only at a conceptual level.

## Draft v0.2 — Methodology foundation

Status: **Current**

- Formalize Detection Capability (CD).
- Formalize Detection Unit (UD).
- Define five baseline threat-scenario phases.
- Connect UD with telemetry and MITRE ATT&CK.
- Define detection, telemetry, visibility, and architecture gaps.
- Introduce early response automation driven by UD.
- Define progressive automation levels and reversible containment.

## Draft v0.3 — Reference threat scenario

Planned:

- Publish one complete end-to-end threat scenario.
- Model Reconnaissance through Impact.
- Define CD and UD for each relevant phase.
- Identify data-source and telemetry requirements.
- Add MITRE ATT&CK mappings.
- Show correlated UD progression.
- Define response and SOAR automation paths.
- Demonstrate early containment in Reconnaissance and Initial Access.

## Draft v0.4 — Coverage and measurement

Planned:

- Detection Coverage model.
- Phase Coverage.
- CD Coverage.
- UD validation coverage.
- Telemetry coverage.
- Automation Coverage.
- Gap severity and prioritization.
- Metrics for detection and response effectiveness.

## Draft v0.5 — Validation and operationalization

Planned:

- UD lifecycle and validation model.
- Testing guidance.
- False-positive and confidence assessment.
- Simulation / purple-team validation.
- Operational governance.
- Change management.
- Framework artifacts and reusable templates.

## Long-term direction

The objective is to provide a vendor-neutral and reproducible methodology that connects:

**Threat Scenario → Detection Engineering → Telemetry → Coverage → Response Automation → Continuous Improvement**
